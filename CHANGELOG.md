# Changelog

## [0.1.0] — first release

- Focus lock: fullscreen kiosk window, blacked-out extra monitors, shortcut blocking,
  Task Manager policy, foreground watchdog, resume after restart.
- Optional guard service that brings a session back before the desktop appears.
- Emergency exit code, session length ceiling and overrun grace as safety nets; `--cleanup`
  and uninstall scripts for recovery.
- Whiteboard with frames, text, sticky notes, shapes, tables, pen strokes and connectors.
- Arrange pages: A4 layout with sections and text boxes, PDF export with embedded fonts.
- Session history.
